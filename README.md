# Portfolio Flask
1. `python -m venv venv` lalu aktifkan (`venv\Scripts\activate` di Windows)
2. `pip install -r requirements.txt`
3. `python app.py` → buka http://127.0.0.1:5000

Edit konten di `data.py`. Foto profil: `static/img/profile.jpg`. Album: taruh foto di `static/img/album/<kategori>/`.
Pesan form kontak tersimpan di `messages.jsonl`.
